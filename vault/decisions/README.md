# Decisiones de Diseño (ADRs)

Registro de decisiones no obvias: por qué se eligió X sobre Y, qué se descartó y por qué, restricciones que no son evidentes en el código.

## Formato de un ADR

```markdown
---
title: ADR-NNN — Título de la decisión
tags: [decisions, adr]
date: YYYY-MM-DD
status: accepted | superseded | deprecated
---

## Contexto
¿Qué problema se estaba resolviendo? ¿Qué restricciones existían?

## Decisión
¿Qué se decidió hacer?

## Alternativas consideradas
¿Qué otras opciones se evaluaron y por qué se descartaron?

## Consecuencias
¿Qué implica esta decisión hacia adelante?
```
